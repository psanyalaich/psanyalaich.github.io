// projects

Selected work

OSCC Histopathology Image Classification

Classifying oral histopathology slides (H&E stained, 230 patients) into Normal vs. Oral Squamous Cell Carcinoma using classical ML with handcrafted features: color statistics, Local Binary Pattern (LBP), and Haralick/GLCM texture descriptors. Systematically compared Random Forest and SVM across magnifications (100× vs. 400×), dataset sizes, and feature sets via 5-fold stratified cross-validation. Best result: SVM + Haralick at 100× achieved AUC 0.988 on balanced sets. Pipeline under validation before deployment on lab-generated data; also exploring deep learning extensions.

⏳ In Progress @ ILS scikit-learn · OpenCV
AMTB Dose-Response: Lipid Droplet Morphology

Statistical analysis of how AMTB (a TRPM8 antagonist) affects lipid droplet size and fluorescence intensity across six concentration groups (Control through 10 µM) in 4,878 droplet observations. After confirming non-normality and unequal variances, applied Kruskal-Wallis + Dunn's post-hoc testing (Bonferroni corrected) for Area, Perimeter, and IntDen. Key finding: 10 µM AMTB consistently reduced all three measures; lower doses showed inconsistent effects. Response was not strictly monotonic at intermediate concentrations.

@ NISER Python · SciPy
Multi-Disease Classification from Serum Metabolomics

End-to-end ML pipeline for classifying multiple chronic diseases from LC-MS serum metabolomics data. Implemented a standardized preprocessing workflow — random forest imputation, log(1+x) transformation, Pareto scaling, and ComBat batch correction to handle inter-study technical variation. Benchmarked eight supervised classifiers (Logistic Regression, Linear and RBF SVM, Random Forest, XGBoost, k-NN, MLP, and PLS-DA) for both binary (disease vs. control) and four-class settings using stratified 5-fold cross-validation, reporting F1-scores and bootstrapped ROC-AUC estimates (95% CI). Mapped discriminative metabolites to KEGG enzyme commission numbers and pathway classes to construct disease–metabolite–enzyme–pathway networks, revealing disease-specific and shared metabolic signatures across conditions.

⏳ In Progress scikit-learn · R · KEGG
Cancer Subtype Classification from Gene Expression

MLP classifiers in PyTorch to distinguish cancer subtypes from bulk RNA-seq profiles. Addressed small-sample, high-dimensional challenges with dropout and batch normalization. Ran ablation experiments to assess architectural choices. Reached >80% validation accuracy.

⏳ In Progress PyTorch
Disease Prediction from Tabular Clinical Data

End-to-end ML pipeline for binary disease prediction: EDA, feature engineering, and training of Logistic Regression, Random Forest, and XGBoost models. Compared performance with ROC-AUC, precision-recall, and calibration curves. AUC > 0.82; SHAP values for interpretability.

⏳ In Progress XGBoost · SHAP
Protein Subcellular Localization Prediction

Investigated whether sequence-derived features (amino acid composition, dipeptide frequencies) are sufficient to predict subcellular localization class. Trained logistic regression and decision tree classifiers; examined which physicochemical features were most predictive. F1-score > 0.70.

⏳ In Progress scikit-learn
